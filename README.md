# LAN APK Sync

Mac 同时共享多个 APK，同一 Wi-Fi 内的 Android 手机通过独立客户端或固定下载页选择下载。支持多选、逐次追加和多个目录监听，运行时不需要外网。

## Android 独立客户端（无需浏览器）

安装“局域网接包” → 扫描 Mac 二维码并保存 → 从 APK 列表选择 → 下载并安装。以后直接打开客户端即可，不用重复扫码。完整列表功能需要 Mac `1.2.0` 和 Android 客户端 `1.1.0`，两端均需更新；原链接和配置自动保留。

客户端内置离线扫码库，不依赖 Google 服务。它替代浏览器扫码和下载，但仍需系统安装授权，**不能保证绕过小米账号要求**。安装、迁移和构建见 [Android 使用说明](docs/ANDROID.md)。

## 首次配置

1. 在路由器中给 Mac 保留固定的局域网 IP；Mac 和手机连接同一可互通的局域网。
2. 打开 `LAN APK Sync.app`，点击“添加 APK（可多选）”，选中两份或更多文件；后续再添加只追加，不替换现有项。也可“添加监听目录”，递归共享目录内全部 APK，目录可以暂时为空。
3. 点击“开始同步”，按系统提示允许本地网络访问和防火墙入站连接。默认端口为 TCP `8787`。
4. 手机客户端首次扫码并确认 Mac，或用浏览器打开完整地址并收藏。之后在同一入口选择所需 APK。
5. 开发正常打包；工具每 2 秒检查，逐文件等待至少稳定 2 秒且 SHA-256 计算前后未变化才发布。一个文件正在写入不影响其他 APK 下载。

## 日常使用

- 开发：添加文件或监听目录，保持 Mac 工具运行。按完整文件路径区分项目，不按 Android 包名合并；同一路径覆盖更新同一项，新路径作为新增项。
- 测试：打开客户端或收藏页 → 选择 APK → 下载 → 按系统提示确认安装。首次需允许对应来源安装未知应用。客户端每 5 秒、网页每 2.5 秒刷新列表；同名 APK 显示不同 ID。
- 移除：APK 卡片的移除按钮只撤销共享，不删除原文件；目录内被移除的文件不会自动重新出现，重新添加该文件或目录可恢复。来源旁的关闭按钮用于取消该来源，其他来源不受影响。
- 重启工具：默认恢复全部文件与目录的权限、移除记录、端口和分享链接；可以关闭“下次打开自动开始同步”。这不等于开机自启动。
- 目录暂时为空或 APK 正在写入：服务仍可打开，手机页面等待新构建并自动更新。页面需要保持打开；没有后台推送或静默安装。

**固定链接要求 Mac IP、端口和访问令牌均不变。** 切换网络或更换 IP 后需要恢复原地址或重新保存链接。停止同步期间入口不可用，再次启动后同一地址恢复；“重置分享链接”则立即作废旧链接。

## 迁移到隔离环境

优先复制构建好的应用，无需在隔离 Mac 安装 Flutter、Dart 或下载依赖。打包和验收步骤见 [隔离环境使用说明](docs/OFFLINE.md)。

联网开发机生成迁移包：

```bash
bash scripts/package_macos.sh
```

输出在 `dist/`：ZIP、SHA-256 校验文件，以及包含 `.app` 和使用说明的目录。不包含 APK、个人设置、访问令牌、SDK 或依赖缓存。

## 源码开发与验证

当前锁文件使用 Flutter `3.27.4` / Dart `3.6.2`；需要可用的 Xcode macOS 工具链。

```bash
flutter pub get --offline --enforce-lockfile
flutter analyze --no-pub
flutter test --no-pub
flutter build macos --debug --no-pub
xcodebuild test -workspace macos/Runner.xcworkspace -scheme Runner \
  -configuration Debug -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath build/macos
flutter build macos --release --no-pub
```

原生测试命令中的 `arch=arm64` 用于 Apple Silicon 开发机；Intel 开发机使用 `arch=x86_64`。Release 产物位于 `build/macos/Build/Products/Release/LAN APK Sync.app`。`--offline` 解析依赖需要本机已有与锁文件匹配的缓存。

## 网络与数据

- 只共享已选择的 APK 或监听目录内的 APK，不提供任意文件或目录浏览，不调用外网服务；下载页不加载外部脚本、字体或图片。
- 每台 Mac 首次生成随机访问令牌，保存在该用户的应用偏好中；完整链接是访问凭据，请只分享给测试人员。可手动重置。
- 文件访问权限使用只读安全书签保存在本机，重新打开应用时恢复；某个书签失效不影响其他来源。文件路径不发送到手机，列表使用不透明的独立 ID。
- APK 通过局域网 HTTP 传输，页面显示 SHA-256；传输记录仅保留在本次运行内。
- 手机无法访问时，检查 Mac 工具是否运行、IP/端口是否变化、macOS 本地网络与防火墙权限，以及 Wi-Fi 是否启用了客户端隔离。
