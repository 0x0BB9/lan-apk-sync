# 隔离环境使用说明

多 APK 列表需要同时更新 Mac `1.2.0` 与 Android 客户端 `1.1.0`，携带两端应用及校验文件。手机客户端按 [Android 使用说明](ANDROID.md) 安装；该客户端不保证解除小米系统的账号安装限制。

## 复制并启动

1. 将 `dist/` 中同名的 ZIP 和 `.sha256` 文件一起复制到隔离 Mac。
2. 在两个文件所在目录执行校验，再解压 ZIP：

   ```bash
   shasum -a 256 -c LAN-APK-Sync-1.2.0-macos.zip.sha256
   ```

3. 将解压出的 `LAN APK Sync.app` 拖入“应用程序”并打开。应用内已包含运行所需的 Flutter 引擎，无需安装 SDK 或联网解析依赖。
4. 如果 macOS 因未公证阻止打开，在核对来源与校验结果后，按照[苹果的说明](https://support.apple.com/102445)，到“系统设置 → 隐私与安全”选择“仍要打开”。本包使用本地临时签名，未进行 Apple 公证。

本工具的部署下限为 macOS 10.15。打包时会列出 `.app` 内实际包含的 CPU 架构；迁移前确认与隔离 Mac 的 Apple Silicon（`arm64`）或 Intel（`x86_64`）匹配。

## 配置固定入口

1. 在隔离 Wi-Fi 的路由器上为 Mac 设置 DHCP 地址保留，确认断开重连后 IP 不变。工具只负责显示地址，不修改路由器或系统网络设置。
2. 打开工具，多选添加隔离 Mac 上的 APK，或添加监听目录。升级已有安装时会自动保留原目录与链接；全新隔离 Mac 需要首次配置。迁移包不包含开发机设置或令牌。
3. 使用默认端口 `8787`，点击“开始同步”。按系统提示允许局域网访问和入站连接。
4. 手机连接同一局域网，用新版客户端扫码一次并保存，或用浏览器打开并收藏完整地址。之后在列表中分别选择下载 APK。
5. 保持“下次打开自动开始同步”开启。以后重新打开工具会恢复目录权限和同一链接；仍需要手动打开应用，不会开机自动启动。

目录内全部 APK（含子目录）都会列出；请只添加可以对测试人员共享的目录。按完整路径区分，不依据包名合并；固定路径覆盖发布可避免积累历史版本。

## 断外网验收

1. 保持 Mac 和手机局域网互通，确认外网不可访问。
2. 选一个空输出目录，开始同步；手机应能打开保存的入口，显示等待构建。
3. 添加 A、B 两份可安装 APK；文件稳定后手机应同时显示两项，分别选择下载，核对大小和 SHA-256。
4. 退出 Mac 工具再打开；无需重新选择目录，手机原书签应恢复可用。
5. 更新 A 的同一路径文件，B 应仍可下载；追加 C 后手机列表自动出现 C，无需重新扫码。
6. 移除 A，原文件应仍在磁盘上，手机不能继续从已移除链接下载 A；B、C 不受影响。重启后 A 仍不应出现，重新添加 A 可恢复。
7. 需要撤销整个入口时点击“重置分享链接”并确认，旧入口应失效；新地址需要重新保存。

若网络不支持设备互访，即使同一 Wi-Fi 也无法传输，请检查客户端隔离、VLAN 和防火墙。关闭或休眠 Mac 后无法下载。手机浏览器页面不提供后台自动下载或静默安装。
